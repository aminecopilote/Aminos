# Aminos

Agent skills bundle in `.claude/skills/`.

## Install on your PC (Windows)

```powershell
git clone -b claude/sweet-pascal-8oyvxa https://github.com/aminecopilote/Aminos
cd Aminos
.\install-skills.ps1
```

Copies all skills to `%USERPROFILE%\.claude\skills` and `C:\Users\verta\Downloads\_certification\.claude\skills`, then restart Claude Code.
